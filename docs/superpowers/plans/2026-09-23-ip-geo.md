# IP 地域解析实施计划

## 目标与边界

- 目标：采集服务按 `client_ip` 解析国家/省/市并随事件落库；后台「访客与设备」展示地域分布，「事件明细」显示地域；历史数据可回填。
- 非目标：不改 SDK，不采集浏览器 GPS 定位，不做地图可视化，不存运营商。
- 数据源：官方 `ip2region.js`（查询代码）+ 官方 xdb 数据文件（`ip2region_v4.xdb` 11MB、`ip2region_v6.xdb` 37MB），数据从 GitHub 下载到 gitignore 目录，不进仓库。

## 关键决策

| 决策 | 结论 | 依据 |
| --- | --- | --- |
| 解析时机 | 采集时每个请求解析一次（一个请求一个 IP） | 内存查询 ~0.6µs/次，无外部调用 |
| 私有/保留地址 | `geo_country='内网'`，省市为空 | xdb 返回 `Reserved|Reserved|Reserved|0|0` |
| 未命中/非法 IP/库未加载 | 三列均为空串，后台显示「未知」 | 不用默认值伪装成功 |
| xdb 缺失 | 启动时 warn 并禁用解析，不阻断采集 | 与 `ADMIN_TOKEN` 缺失同策略 |
| IPv4-mapped IPv6（`::ffff:a.b.c.d`） | 剥离前缀走 v4 库 | v6 库对该形式返回空 |
| 依赖注入 | `buildApp(config, pool, geo)`，测试注入桩解析器 | 集成测试不依赖 48MB 数据文件与网络 |

## 契约变更

- 迁移 `0003_geo`：`track_events` 新增 `geo_country / geo_province / geo_city text NOT NULL DEFAULT ''`；down 删除三列。
- `DevicesStats.geo = { country, province, city }: Distribution[]`；省/市为空时回退到上一级名称。
- `EventRow` 新增 `geoCountry / geoProvince / geoCity`。
- 配置新增 `GEO_XDB_DIR`（默认 `packages/server/data/geo`）。
- 脚本新增 `geo:download`（下载并校验 xdb）、`backfill:geo`（按 distinct `client_ip` 回填三列为空的历史行）。

## 任务

1. shared 类型 + 迁移 0003 + `.gitignore` 数据目录。
2. `src/geo.ts`：`parseRegion`、`createGeoResolver(v4, v6)`、`loadGeoResolver(dir)`；单测覆盖解析、IP 版本路由、非法输入。
3. `db.insertTrackEvents` 增加 geo 参数；`buildApp` 注入解析器；`track.test` 用 `X-Forwarded-For` 断言三列。
4. `stats/devices.ts`、`stats/events.ts` 输出地域；seed 按访客分配 IP；`stats.test` 断言分布与明细。
5. `scripts/download-geo.ts`、`scripts/backfill-geo.ts`；`server.ts` 加载真实解析器。
6. admin：`Devices` 增加地域三列分布，`Events` 增加地域列；fixtures 与测试同步。
7. demo 端到端：`TRUST_PROXY=true`，下载 xdb，浏览器真实访问（内网）+ `curl` 注入公网 IP，后台核对；执行 `backfill:geo`。

## 验证与回滚

- 验证：`npm run build && npm run lint && TEST_DATABASE_URL=... npm test`；demo 后台数值与 `psql` 一致。
- 回滚：`npm run migrate -- down` 回退 0003；删除 `GEO_XDB_DIR` 数据文件即禁用解析，采集不受影响。
